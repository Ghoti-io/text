# Disagreements between this library's XML parser and the pinned references
# (libxml2 and expat, containers/xml), one per line:
#
#     <input> TAB <signature> TAB <class> TAB <reason>
#
# The input is a W3C suite case id, `seed:<file>` for a fuzz seed, or `gen:<12 hex>`
# for a generated document (the first 12 hex digits of the SHA-256 of its bytes).
# The signature is what each program said: `ours=` A(ccept), R(efuse) or D:<status>
# (declined: an encoding, a version or a limit this parser does not read), `xml2=`
# and `expat=` the references run namespace-aware, `plain=` expat without
# namespaces; `dump=` names the references whose event list differed from ours, and the
# `#` after it is a digest of the event lists, so a different difference for the same input
# fails the run as a changed signature.
#
# tools/oracle/xml_diff.py fails the run on a disagreement with no line here, on a
# line whose disagreement is gone, and on a line whose signature has changed. There
# is no class for "ours is wrong": that is fixed, with a test.
#
#   reference-wrong    a reference accepts or refuses against the specification
#   version-specific   the pinned reference's behaviour, not the standard's
#   spec-ambiguity     the specification can be read either way
#   representation     equal information, reported differently
#   reference-scope    a reference does not read this encoding or its presentation
#   scope-dtd          needs DTD processing, which this parser does not do
#   scope-unsupported  an encoding or version this parser declines to read
#   scope-limit        a limit this parser enforces and the references do not
#
# A class here is a measurement, not a reading: `tools/oracle/xml_classify.py`
# assigns scope-dtd only when the same document with its document type declaration
# removed is agreed on by all three programs, reference-scope only when the same
# document as UTF-8 is, reference-wrong for a reference that contradicts the pinned
# W3C XML/Namespaces expected class or XML 1.1 normalization, and so on. XML 1.1
# cases are compared wherever the pinned implementations produce answers.
# The lines were produced by `tools/oracle/run-xml-oracle.sh --propose` and read.

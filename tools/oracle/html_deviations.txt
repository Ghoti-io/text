# vectors (web-platform-tests html/syntax/parsing/resources/*.dat, pinned by commit
# in tools/html/WPT_COMMIT). The gate is tools/oracle/html_vectors.py: a vector a
# reference does not reproduce must be listed here, a listed one that now passes is
# stale and fails the run, and the digest locks the expected and the actual tree so
# that a *different* failure of the same vector cannot hide behind the old entry.
#
# Columns, tab separated: vector (file#n), reference, digest, class, reason.
#
# The pinned vectors are the standard as of the WPT commit; both references are
# older than that. html5lib 1.1 is from 2020. parse5 8.0.1 is current as a release but
# the vectors follow the standard's living text, which has since moved (a rewritten
# 'in select' insertion mode for customizable select, the search element, processing
# instructions as nodes, form handling in templates). That is the whole of why the
# list is long, and it is why html_diff.py never trusts a reference on a construct
# the standard has since changed: its trees are generated from the vocabulary and
# nesting the standard has not changed, and a divergence there is investigated
# against the standard, not against the reference.

# Divergences of the HTML tree builder from html5lib 1.1 and parse5 8.0.1 that are expected and
# understood, for the default population of tools/oracle/html_tree_diff.py (6,000 generated
# documents, 3,000 mutated ones, the in-scope tree-construction vectors the references can judge,
# and tools/conformance/html_tree_extra.dat; seed 1). The gate is html_tree_diff.py: it fails on a
# divergence of a kind that is not here, on an entry that no longer occurs, and on one whose count has
# changed (the count is the signature of the population). A count of `hunt` is an entry seen only
# on the larger populations a hunt generates.
#
# Columns, tab separated: key, count, class, reason.
#
# The key is `<who>:<why>`. <why> is the first of the elements the reference reads by older rules (KNOWN_OLD in
# the script) that the document holds, and the entry is there only because the divergence was verified: the
# document was asked again with those elements removed, and this library and the reference then agreed.
#   parse5:<name>        parse5 differs from this library (html5lib does not, or is not asked).
#   both:<name>          both references differ from this library and agree with each other.
#   three-way:<name>     both references differ from this library and from each other; judged against parse5.
#   html5lib:alone:<name>  html5lib differs and parse5 agrees with this library.
#   html5lib:alone:unverified  the same, and removing those elements does not make html5lib agree: its
#                        older adoption agency and Noah's Ark rules, for which no element name stands.
# parse5 8.0.1 is the newer reference; html5lib 1.1 is from 2020, the oldest.
#
# Classes: standard-newer (the standard has moved past both references), reference-old (the
# reference is older than the standard), reference-wrong (it disagrees with the standard in a way no
# change explains).
#
# **A divergence in a document with none of the elements the script knows to be read by older rules
# is never listed**: it is an unexplained divergence, and fails the run.
#

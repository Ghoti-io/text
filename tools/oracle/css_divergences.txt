# Where tinycss2, cssparser and csstree differ from this library's CSS Syntax, one line each, in the default
# population (css_diff.py: --count 20000 --seed 1, the css-parsing-tests and WPT inputs besides).
#
#   <mode> TAB <reference> TAB <class> TAB <divergences> TAB <shortest input of the class> TAB <reason>
#
# A class is an experiment (css_classes.py): an input transformation that takes one cause of difference out,
# and a divergence is in a class when neutralizing the classes of its set makes this library and the reference
# agree about the transformed input. A divergence with several causes counts under each. The reason names who
# holds what and quotes the sentence of the served CSS Syntax Editor's Draft (retrieved 2026-10-21) that decides it,
# or the reference's documented behavior where the draft is silent.
#
# tools/oracle/css_diff.py fails on a divergence in no class, on a class here that has no divergence (stale), on a
# count that differs (the default population is fixed; a hunt with another count or seed is held to the classes only)
# and on a reason that is not the class's. `css_diff.py --propose` writes the lines; they are read before they are
# committed, never taken as they come.
#
# Which references share code: none of the three (Python, Rust, JavaScript, written by different people for different
# engines). They share an age: tinycss2 and cssparser follow the Candidate Recommendation Drafts before the one this
# library follows, csstree predates CSS Nesting, and most classes below are that age.

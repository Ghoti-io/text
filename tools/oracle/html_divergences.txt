# Divergences of the XHTML write mode from html5lib and parse5 that are expected and
# understood: every tree on which an HTML parser builds something other than the tree that
# was written, grouped, for the default population of tools/oracle/html_diff.py (4000
# generated trees, seed 1; the W3C XML suite; the expected trees of the tree-construction
# vectors). The gate is html_diff.py, and it fails on a divergence that is not here, on an
# entry that no longer occurs, and on one whose count has changed (the count is the
# signature: a different tree for the same entry is a different count or a different entry).
# A count of `hunt` is an entry seen only on the larger populations a hunt generates (other
# seeds, 100,000 trees): it need not occur in the default one, and if it does, its count is
# written here.
#
# Columns, tab separated: key, count, class, reason.
#
# **No tree without hazards is ever listed as a writer defect.** That is the claim under test
# and the gate has no entry for it: such a tree is fixed in the writer, or becomes a new kind of
# hazard (and then appears here, under that kind). The two sorts of key:
#
#   hazard:<first hazard>:<who differed>   a tree the writer reported a hazard in, and the
#       kind of its first hazard. The hazard is the reason: the entry says what an HTML
#       parser does about it. "Who" is both references, or the one that differed. A tree with
#       several hazards is counted under its first; a hazard that does not make HTML build
#       another tree (the list is conservative in places) is no entry, because nothing
#       diverged. What differed is in the report the gate prints, not in the key: the same
#       first hazard turns up as a different first difference from tree to tree.
#
#   ref:<who>:<cause>   a tree with NO hazards on which one reference reads it as written and
#       the other does not. These are not the writer's: the cause is established (see
#       KNOWN_CAUSES in html_diff.py, each with the vectors in html_deviations.txt that show
#       it) and the standard is the arbiter. A cause not in that table fails the run.
#
# Classes: hazard-expected (the hazard says an HTML parser builds something else), html5lib-wrong
# (a reference is wrong against the standard), reference-old (the reference predates a change to
# the standard), standard-unclear (the standard can be read either way).

Here both references build a tree other than the one written.

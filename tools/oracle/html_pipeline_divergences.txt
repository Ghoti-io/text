# Divergences of this library's whole HTML pipeline from html5lib 1.1 and parse5 8.0.1 that are expected and understood, for the default
# population of tools/oracle/html_pipeline_diff.py (the documents, fragments and tree-construction vectors of the tree differential, 1,500 generated
# documents and their mutations, put through the public API as bytes in the encodings of the Encoding Standard with and without a byte order mark,
# `<meta>`, transport label and default; seed 1). The gate is html_pipeline_diff.py: it fails on a class that is not here, on one that no longer
# occurs, on one whose count has changed (the count is the signature of the population), on a divergence no class accounts for, and on a reference
# that could not answer. A count of `hunt` is a class only the larger populations a hunt generates reach.
#
# Columns, tab separated: key, count, class, reason. The key is one of
#
#   decision:<departures>     this library's encoding decision against html5lib's: explained by the smallest set of html5lib's departures
#                             (html_sniff_divergences.txt, the second reading of the standard in html_sniff_model.py)
#   reading:<encoding>:<kind> what the Encoding module decodes against what html5lib's codec makes of the same bytes under the same decision;
#                             this library equals the model written from the standard (encoding_model.py, indexes.json) in every one of them, and
#                             the key says how the codec differs
#   serialization:<ref>:<f>   this library's serialization against the reference's own, for trees the two agree on; <f> is a feature of
#                             html_serialize_divergences.txt, found from the pieces by which the two outputs differ, not by deleting anything
#   tree:<route>:<who>:<why>  the trees. <route> is `text` (the text this library decoded, parsed by the references) or `reread` (the serialization
#                             this library wrote, parsed by the references and by itself); <who> is html5lib:alone, parse5, both or three-way
#                             (the tree differential's); <why> is what the **minimal reproducer** holds. Each divergence is reduced by delta
#                             debugging over its tokens (each step asks this library and the reference again, so that the reproducer still
#                             diverges and nothing else of the document is in it) and then named by the elements the reproducer holds that a
#                             reference reads by older rules (KNOWN_OLD of html_tree_diff.py, with the tree differential's reasons and its hand-worked
#                             witnesses), by the attribute whose line is the first to differ, or by the fragment context. A divergence whose
#                             reproducer holds none of these fails the run and is printed with its reproducer.
#
# Classes: standard-newer (the standard has moved past the reference), reference-old (the reference is older than the standard), reference-wrong
# (it disagrees with the standard in a way no change explains). The standard is the text served at html.spec.whatwg.org on 2026-10-13.
#
# A limit of the method, and what stands in for it: a reproducer named by an element explains any divergence it holds, so a defect of this library in
# the same construct could hide there. The reproducers are minimal (every other token and attribute is gone), the tree differential's witnesses check the
# deviation itself on every run (html_tree_diff.check_witnesses, run by the tree gate), and this gate holds this library to the vectors' own expected trees
# through the same runner (make conformance-html-tree).
#

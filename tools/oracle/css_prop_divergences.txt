# Divergences of this library from Chromium 156 and Firefox 158 (Stylo) that are expected and understood, for the default population of
# tools/oracle/css_prop_diff.py (the core scope: the controls, the probe `initial` and the witness of every property, and the items of this
# list's own witnesses; seed 1). The gate is css_prop_diff.py: it fails on a divergence of a key that is not here, on an entry that no longer
# occurs, on one whose count has changed (the count is the signature of the population), on a witness that does not hold, on a control that
# is not classified as it was and on more entries of class `ours` than the ceiling. A hunt (CSS_PROP_ORACLE_SCOPE=full, with a count of 100,000
# or more) asks far more, and what it finds is a finding: a kept reproducer, a vector, then a fix or an entry here.
#
# Columns, tab separated: key, count, class, digest, reason. The digest is a hash of every item of the key (property, value and the three answers of
# each), so that a key whose items are the same in number and not in what is said of them fails the run (DIGEST) and is looked at again.
#
# The key is `<pattern>:<property>:<feature>`. The pattern: `support:E` (the engines E refuse `initial` for the property, which every engine
# that has a property accepts: they do not have it, and nothing else is compared for them), `acc:ABC` (the acceptances of ours, Chromium and
# Firefox as 1, 0, or - for an engine that does not have the property), `ser:` (the serializations of the readers that accept, the ones that
# write alike joined by `=`, A ours, B Chromium, C Firefox), `sup:E` (an engine's CSS.supports disagrees with its setProperty). The feature is
# the smallest item of the pattern and property written as tokens with numbers (N), dimensions (D) and strings (S) abstracted; every larger
# item that has its tokens counts for it (the HTML differentials' argument, made with the tokens of the value).
#
# Classes: standard-newer (the served draft is ahead of the engines), reference-old (an engine has not implemented what the draft says),
# reference-wrong (it disagrees with the draft in a way no change of the draft explains), legacy-compat, and ours (a defect of this library:
# when the two engines agree and this library differs it is this library's until the draft says otherwise; the ceiling only goes down and a
# finished list holds none). The sentence of the served draft (Editor's Drafts of 2026-10-26) is quoted where it decides.
#

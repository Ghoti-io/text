# Divergences of this library from Chromium 156 and Firefox 158 (Stylo) on `getComputedStyle()`, expected and understood, for the default population of
# tools/oracle/css_style_diff.py (200 generated trees, the SVG fixtures, the presentation attributes and the generated values, seed 1, both color schemes). The
# gate fails on a divergence of a key that is not here, on an entry that no longer occurs, on one whose count has changed (the count is the signature of the
# population), on one whose digest has changed, on a witness that does not hold, on a control that is not as it was and on more entries of class `ours` than
# the ceiling (CSS_STYLE_ORACLE_MAX_OURS, 0 for a finished list). A hunt (CSS_STYLE_ORACLE_COUNT of 100,000 or more, other seeds) asks far more, and what it
# finds is a finding: a kept reproducer, a vector, then a fix or an entry here.
#
# Columns, tab separated: key, count, class, digest, reason. The digest is a hash of every item of the key (document, element, property, scheme and the three
# answers of each), so a key whose items are the same in number and not in what is said of them fails the run and is looked at again.
#
# The key is `<pattern>:<property>:<feature>` as in css_prop_diff.py: `support:E` (the engines E refuse `initial` for the property, which every engine that has
# it accepts), `acc:ABC` (whether ours, Chromium and Firefox have a value: 1, 0 or -), `ser:` (the serializations of the readers that have one, the ones that write
# alike joined by `=`, A ours, B Chromium, C Firefox). The feature is the smallest declaration of the pattern and the property, with numbers (N), dimensions (D),
# percentages (P) and strings (S) abstracted; `attr :` is a presentation attribute, `style :` a declaration of the style attribute.
#
# Classes: standard-newer (the served draft is ahead of the engines), reference-old (an engine has not implemented what the draft says), reference-wrong (it
# disagrees with the draft in a way no change of the draft explains), legacy-compat, unspecified (the draft leaves the answer to the implementation, so every
# answer is a correct one and this library's is a choice), and ours (a defect of this library: when the two engines agree and this library differs it is this
# library's until the draft says otherwise; the ceiling only goes down and a finished list holds none). The sentence of the served draft (Editor's Drafts of
# 2026-10-26) is quoted where it decides, and the gate refuses a class that says a draft decides without a quoted sentence of 25 characters or more.
#
# Every `support:` entry is classified by the probe itself, and its witness is the property with `initial`.
